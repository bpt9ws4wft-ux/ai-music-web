# AI Music Web

- 在线体验（网站）：https://bpt9ws4wft-ux.github.io/ai-music-web/
- GitHub 仓库（代码）：https://github.com/bpt9ws4wft-ux/ai-music-web

## 项目目标
AI Music Web 是一个单文件前端原型，用来演示“本地浏览器内的音乐创作辅助流程”。

当前版本专注于：
- 上传本地音频
- 浏览器录音
- 播放音频
- 波形可视化
- 基础音频分析
- 基础音高检测
- 音准偏差分析
- 模拟 Auto-Tune 修正路径
- 规则化 Beat 推荐

它不连接后端，不调用真实 AI，也不做真实音频生成。

## 当前版本功能

### v0.1
- 页面基础结构
- 视觉样式与单页布局

### v0.2
- 上传本地音频文件
- 播放上传的音频
- 展示文件名称

### v0.3
- 浏览器录音功能
- 录音计时
- 录音后播放

### v0.4
- 音频波形可视化
- 结果预览区基础 UI

### v0.5
- 基础音频分析
- 显示时长、峰值、平均音量和提示

### v0.6
- 基础音高检测
- 显示主要频率、音名和可信度

### v0.7
- 音准偏差分析
- 支持调性和音阶选择
- 显示当前音名、目标修正音名、偏差和建议

### v0.8
- 模拟 Auto-Tune 修正路径
- 显示原始偏差、修正强度、修正后偏差和修正方向

### v0.9
- 规则化 Beat 推荐方案
- 基于音高、调性、音阶、音准偏差和 Auto-Tune 强度给出前端规则推荐

## 如何打开项目

直接打开项目根目录下的 `index.html` 即可。

在浏览器中：
1. 进入项目文件夹
2. 双击 `index.html`
3. 或者把 `index.html` 拖进浏览器窗口

## 当前不包含什么

- 不接后端
- 不调用真实 AI
- 不做真实修音
- 不生成真实 Beat 音频
- 不做真实音频合成
